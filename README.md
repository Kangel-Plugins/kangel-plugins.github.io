# Kangel Plugins Manager — правила публикации

Статическая страница правил на Vue 3 и компонентах Material Web (Material Design 3) с русской и английской версиями. Тексты находятся в `src/translations.js`, оформление — в `src/style.css`.

Установка и запуск локального сервера:

```sh
npm install
npm run dev
```

Адрес появится в терминале. Для production-сборки выполните `npm run build`; результат находится в `dist/`. Для GitHub Pages нужно публиковать содержимое `dist/`. Шрифт загружается с Google Fonts.

Иконки: [HackerNoon Pixel Icon Library](https://github.com/hackernoon/pixel-icon-library), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), без изменений.

Доступны два оформления: Material Design 3 (по умолчанию) и [NeedyWebUI](https://github.com/ArThirtyFour/NeedyWebUI). CSS NeedyWebUI загружается с jsDelivr при выборе этого оформления; библиотека распространяется под GPL-3.0.
